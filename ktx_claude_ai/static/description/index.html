DOS FORMAS DE USARLO

Cómo usarlo

Chat dentro de Odoo

Abre Claude AI → Chat y escribe, por ejemplo:

• "Crea un contacto Acme con NIT X"
• "Restablece a borrador las facturas 5 y 7"
• "Cambia el cliente de estas 10 facturas a Y"

Conector remoto (Claude.ai / escritorio)

1. Ajustes → Claude AI → Conector remoto: actívalo y copia la URL /claude/mcp.
2. En Claude.ai → Settings → Connectors → Add custom connector, pega la URL e inicia sesión (OAuth).
3. Para escritorio/API: genera un token estático y úsalo como Bearer.

KTX 4 — Corporativo

Factura / DTE en tamaño Carta, con estructura tipo ERP más limpia que SAP.

Estructura corporativa

Banda de cabecera sólida, cajas Emisor/Receptor, franja de datos y tabla con cuadrícula y filas alternas.

Acento configurable

Usa cfg['accent_color'] con un default corporativo (navy). El texto sobre el acento se calcula por contraste.

Complemento, no reemplazo

Depende de ktx_fel2odoo_format. Agrega la opción KTX 4 reutilizando toda la lógica del base.

3 tamaños de papel

Disponible en Carta, Media Carta y Ticket (impresora térmica 72mm). Frases SAT, total en letras, impuestos y datos de certificación con QR.
